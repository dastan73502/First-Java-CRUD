# First-Java-CRUD

Simple Java CRUD application built with Spring Boot, Spring Data JPA, H2 and Vaadin, based on the official Spring guide "Creating CRUD UI with Vaadin".

## Features

- list customers in a grid
- filter by last name
- create, edit and delete customers

## Run locally

Requirements: Java 17+ and Maven (or IntelliJ IDEA).

```
mvn spring-boot:run
```

Then open http://localhost:8080
